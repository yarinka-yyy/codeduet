Code Duet — скилл для Codex, который объединяет **GPT в Codex** и **DeepSeek в OpenCode** в общий процесс разработки. Опишите, что хотите сделать: GPT изучит проект и подготовит план, DeepSeek напишет код, а GPT проверит результат и направит доработку.

Вы следите за работой в своём чате Codex. План хранится в проекте, а в конце вы получаете отчёт об изменениях и проверках. Code Duet берёт на себя передачу заданий и результатов между двумя инструментами.

## Как это работает

![Задача поступает GPT для планирования, затем DeepSeek для реализации и снова GPT для проверки. Исправления возвращаются DeepSeek, а готовый результат — пользователю.](assets/readme/how-it-works.png)

<details>
<summary>Описание процесса</summary>

1. **Вы описываете задачу.** GPT изучает проект и составляет план с чёткими границами работы и критериями готовности.
2. **DeepSeek выполняет.** GPT отправляет задание в OpenCode. DeepSeek вносит изменения и запускает предусмотренные планом проверки.
3. **GPT проверяет.** Когда DeepSeek заканчивает работу, GPT изучает реальные изменения и сверяет их с планом.
4. **Доработка или завершение.** Если нужны исправления, GPT собирает их в одно задание. Когда критерии выполнены, он сообщает о результате, проверках и оставшейся работе.

</details>

## Что Code Duet берёт на себя

| | Чем это полезно |
|---|---|
| **Общий план** | Задача, границы работы, прогресс и результаты проверки хранятся вместе в проекте. Можно создать новый план или продолжить существующий, в том числе из Improve Codex. |
| **Передача заданий и результатов** | Задания, вопросы исполнителя и результаты передаются между Codex и OpenCode без ручного копирования сообщений. |
| **Ожидание без лишних ходов GPT** | Фоновый наблюдатель следит за вопросами, завершением и ошибками. Пока DeepSeek работает, GPT завершает свой ход и продолжает в том же чате, когда требуется его участие. |
| **Отдельная проверка** | DeepSeek реализует задачу, GPT изучает файлы и проверяет результат. Они работают над проектом по очереди. |
| **Сохранение контекста** | Привязка к сессии, идентификаторы заданий и записи в плане позволяют продолжить работу с нужной задачей. |

Локальный помощник связывается с запущенным движком OpenCode. Обычная работа Code Duet не занимает мышь и клавиатуру.

## Быстрый старт

### 1. Подготовьте инструменты

Нужны Windows, **настольное приложение Codex**, **OpenCode Desktop** и **Node.js 24**. В OpenCode должен быть доступ к **DeepSeek V4.1 Flash через OpenCode Go**. Откройте проект в Codex и запустите OpenCode Desktop.

Поддерживаемые версии движка OpenCode: **2.1.4** и **2.2.0**. Помощник использует встроенные модули Node.js; устанавливать npm-зависимости не нужно.

### 2. Установите скилл

Выполните в PowerShell:

```powershell
git clone https://github.com/yarinka-yyy/codeduet.git
Set-Location codeduet
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex\skills" | Out-Null
node .\tools\package.mjs "$env:USERPROFILE\.codex\skills\code-duet"
```

Папка назначения `code-duet` должна быть новой. Если скилл уже установлен или нужен только в одном проекте, см. [установку и локальный запуск](references/runtime.md).

### 3. Дайте GPT задачу

В чате Codex, открытом в вашем проекте:

```text
$code-duet
Добавь экспорт в CSV на страницу отчётов. Изучи проект, подготовь план
и организуй реализацию и проверку с DeepSeek в OpenCode.
```

Можно попросить Code Duet работать по готовому плану. Он использует сохранённую привязку чата к OpenCode или создаёт сессию для проекта. Если нужна конкретная существующая сессия OpenCode, выберите её явно; подробнее — в [описании работы с существующими сессиями](references/existing-session.md).

## Вопросы и доработка

Если DeepSeek задаёт вопрос, GPT отвечает в рамках задачи и ваших разрешений. Решения, требующие вашего участия, возвращаются к вам. После реализации GPT проверяет работу и отправляет исправления одним заданием.

Для каждого плана предусмотрено до **20 циклов исправлений** после первой реализации. Счётчик сохраняется при продолжении плана. Итоговый отчёт объясняет, что изменилось, что проверено и что осталось сделать.
